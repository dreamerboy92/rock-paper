# 🪨📄✂️ Rock Paper Scissors Game

A simple and fun Rock Paper Scissors game built with Python. This project allows users to play the classic game against the computer using a command-line interface.

## 🚀 Features

- Play Rock, Paper, Scissors against the computer  
- Random choice generation for the computer  
- Score tracking  
- User-friendly interface  
- Written in clean and simple Python code  

## 🧠 Game Rules

- **Rock** beats **Scissors**  
- **Scissors** beats **Paper**  
- **Paper** beats **Rock**  
- If both the user and computer choose the same option, it's a **draw**  

## 🛠️ Technologies Used

- Python 3
